# e-content · дизайн-система

Одна страница с вариантами компонентов будущей аналитической системы для авторского IT-блога. Название закреплено: **e-content**. Работа изолирована в `content-manager`.

## Запуск

Из этой папки запустите `start.cmd`. Скрипт найдёт npm в стандартной папке Windows, при необходимости установит зависимости и поднимет сайт.

```powershell
npm ci --workspaces=false
npm run dev
```

Адрес: http://127.0.0.1:5186/. Нужен Node.js 24 LTS. Зависимости и lockfile находятся в этой папке.

## Разделы галереи

- **Элементы:** варианты кнопок, статусов, поиска, фильтров, переключателей, диалогов и индикаторов выполнения.
- **Цех:** «Изометрия», «Связи» и «Линия». SVG-схема встроена в страницу; выбранный участок раскрывает процесс в правой панели без размытия фона. Есть отдельные источники Telegram/TikTok, запуск участка, полный цикл и остановка.
- **Библиотека:** полупрозрачные объёмные папки, коллекции, поиск, фильтры, просмотр материалов и Markdown.
- **Графики:** плавные линии и области за 7/30/90 дней, управляемая легенда, подсказки и таблица; воронка, полосатая кольцевая диаграмма, источники со спарклайнами и карта активности.
- **Типографика:** Manrope, Onest и системный шрифт; три варианта знака — «Разрез», «Слой», «Модуль». Выбор шрифта и знака сохраняется в браузере. Токены скачиваются в JSON.

Палитра строго монохромная: чёрные поверхности, серые элементы и белые акценты. Базовый текст — 16 px, подписи элементов — 14 px, второстепенный текст — от 12 px на настольном экране. Анимации учитывают reduced motion; у интерактивных элементов есть клавиатурное управление и видимый нейтральный фокус.

## Границы этапа

Показатели и материалы демонстрационные. Проигрывание процесса не запрашивает Telegram, TikTok или модели. Экспорты действительно создают файлы.

Серверное хранилище Markdown, авторизация, реальный сбор и MCP ещё не подключены. Эта галерея предназначена для выбора деталей, из которых затем будет собираться приложение.

## Исходники и проверка

`src/LabApp.tsx` — оболочка галереи, компоненты и типографика. `src/lab/` — цех, библиотека, графики, общие элементы и стили.

```powershell
npm run build
npm run check:ui
npm run format:check
```

`build` создаёт статический сайт в `dist`. `check:ui` запускает сценарии из `scripts/check-lab.mjs` в установленном Microsoft Edge; сайт перед проверкой должен быть запущен. Для просмотра сборки используйте `npm run preview`, предварительно освободив порт 5186.

## Источники

Референсы пользователя определяют визуальное направление. Использованы применимые принципы [taste-skill](https://github.com/Leonxlnx/taste-skill) и [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines).

[Manrope](https://github.com/googlefonts/manrope) и Onest размещены локально, без CDN. Лицензии SIL OFL: `public/fonts/Manrope-OFL.txt` и `public/fonts/OFL.txt`. Иконки — Lucide; движение — Motion; диаграммы и геометрия — SVG.

## VPS

`Dockerfile` и `deploy/nginx.conf` остаются заготовками для размещения статической сборки. Контейнер и выпуск на VPS не выполнялись. Будущие пользовательские Markdown-файлы должны храниться вне публичной директории и выдаваться через авторизованный API.
